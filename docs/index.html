What it does

DeStack is a Chrome extension (Manifest V3) that hides Substack's algorithmic home feed and the "Related notes" section, so there's nothing left to scroll endlessly. Your subscriptions, newsletters and posts still work as usual.

Who it's for

People who want a calmer Substack without infinite scrolling: readers who open Substack for one post and don't want to lose an hour to the feed.

Install

Coming soon: the Chrome Web Store listing isn't live yet. Until then, install from source:

  1. Download or clone the repository.
  2. Open chrome://extensions and enable Developer mode.
  3. Click Load unpacked and select the DeStack folder (the one containing manifest.json).
  4. Visit Substack and the home feed is gone.
git clone https://github.com/mannybuildstech/DeStack.git

Privacy

DeStack collects no data. It has no analytics, no accounts, and makes no network requests. It only runs on Substack pages to hide parts of the page on your device. Read the privacy policy.
